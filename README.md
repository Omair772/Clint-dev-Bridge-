# Client Dev Bridge 🚀

Client Dev Bridge is a professional mobile platform designed to bridge the gap between clients and developers. The application integrates AI-driven project analysis to streamline requirements, a dynamic pricing engine, and secure payment processing.

---

## 🚀 Key Features
* **AI-Driven Analysis:** Intelligent project requirement gathering and automated analysis.
* **Dynamic Pricing Engine:** Real-time cost estimation based on selected project features.
* **Project Lifecycle Management:** Full tracking from initial concept to final delivery.
* **Secure Payments:** Integrated payment workflows for project milestones.
* **Role-Based Access:** Dedicated dashboards for Clients, Employees, and Admins.

---

## 🛠 Tech Stack
* **Frontend:** Flutter (Mobile Framework)
* **Backend:** Firebase (Firestore, Authentication, Cloud Functions)
* **Design:** Glassmorphism UI (Figma/Adobe XD)
* **AI Integration:** Integrated analysis logic.

---

## 🏗 Project Structure
```text
lib/
├── core/            # Constants, Themes, and App Colors
├── screens/
│   ├── ai/          # AI-based project input logic
│   ├── admin/       # Admin dashboards
│   ├── client/      # Client dashboards and project tracking
│   ├── employee/    # Employee task management
│   └── auth/        # Login and registration screens

```

## ⚙️ How to Run

1. **Clone the repository:**
```bash
git clone [YOUR_REPO_URL]

```


2. **Install dependencies:**
```bash
flutter pub get

```


3. **Configure Firebase:** Add your `google-services.json` (for Android) and `GoogleService-Info.plist` (for iOS).
4. **Run the app:**
```bash
flutter run

```
